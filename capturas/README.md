# Capturas de tráfico y pruebas

Aqui se guardan:
- Capturas .pcap de Wireshark
- Capturas de pantalla de los escaneos Nmap
- Resultados de Metasploit
- Logs del firewall pfSense

## Nomenclatura recomendada
- `nmap-dmz-basico.png`     → Escaneo básico a la DMZ
- `nmap-lan-bloqueado.png`  → Intento de escaneo a la LAN (bloqueado)
- `wireshark-ataque.pcap`   → Captura durante prueba de ataque
- `pfsense-logs.png`        → Logs del firewall con intentos bloqueados
